# credit_cards_india vs debate_cv: standards gap audit (2026-11-01)

Read-only audit. Nothing in either repo was changed. The credit_cards_india working tree had 691 uncommitted entries (data edits owned by someone else) and was not touched; `data/` and git state were only read.

Sources read. debate_cv: `docs/CODING_STANDARDS.md` (40 rules), `CODE_STANDARDS-CHECKLIST`, `CODE_STANDARDS_BASELINE`, `DATABASE_STANDARDS-CHECKLIST`, `UI_UX_STANDARDS.md` (43 rules), `DESIGN_INSTRUCTIONS.md`, `CI_PLAN`, `ci.yml`, `.prettierrc`, `eslint.config.mjs`, `knip.json`, `check-ratchet.mjs`, `check-file-size.mjs`, `tsconfig.json`, `CLAUDE.md`, `AGENTS.md`, PR template, `globals.css`, and the reports folder (best-practices doc, ui-ux research, the UI-precision memory). credit_cards_india: README, `docs/SCHEMA.md`, `DECISIONS.md`, `CONTRIBUTING.md`, `UI_UX_TODO.md`, `schema/*.json`, `scripts/validate.py`, both workflows, `site/` configs, styles, components, app, lib, and `booking-savings/`.

Effort: S under half a day, M about a day, L multi-day. Risk is risk of breaking something or causing churn.

## 0. Headline findings

1. **CI does not build or test the site at all.** `validate.yml` runs only Python (validate.py plus 4 unit-test scripts). The 30 vitest files, `tsc`, lint and `next build` run nowhere in CI. There is no required check; this is the biggest gap.
2. **No `CLAUDE.md` or `AGENTS.md`, no PR template, no `.gitattributes`, no Prettier, no `.editorconfig`.** Agent rules live only in `docs/TODO.md` (1,533 lines), `CONTRIBUTING.md` and skills.
3. **Stack is one major behind on most things** (registry check, 2026-11-01, `npm view`): Next 15 vs 16.4.3 current; Tailwind 3.4 vs 4.3.3; ESLint 9 vs 10.14.0; Vitest 4 vs 5.0.5; TypeScript ^5.6 vs 7.0.2 (debate_cv deliberately stays on ~6.0 until typescript-eslint supports 7). `next lint` plus `.eslintrc.json` is the legacy path (removed in Next 16). Node and Python are unpinned.
4. **The data side is strong already** (JSON Schema 2020-12, `additionalProperties:false` on 42 objects, effective-dated records, source provenance with grading, id uniqueness, FK-style lints, weekly link check). Gaps are versioning, migrations, backups and CI strictness, not integrity.
5. **Design tokens and contrast tests are already good** (`tokens.css`, `design-tokens.test.ts`). Gaps: no icon library discipline (hand-rolled SVGs plus 7 emoji in UI), no mono/tabular numeral rule, no spacing/width scale beyond `max-w-6xl`, no paging on a 368-card grid, and the UI_UX_TODO plans emoji chips (the opposite of debate_cv's "no decorative emoji, label first").
