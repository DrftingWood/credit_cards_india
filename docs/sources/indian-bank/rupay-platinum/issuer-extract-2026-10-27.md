# Indian Bank RuPay Platinum issuer review — 2026-10-27

## Sources checked

- [Current Indian Bank MITC](https://indianbank.bank.in/documents/d/guest/MITC-FINAL): fees and finance charges.
- [Issuer credit card features sheet](https://indianbank.bank.in/documents/d/guest/credit-card-features-and-benefits-6-1-): card-specific features, earn rate and historic lounge statement.
- [Indian Bank credit-card catalogue](https://indianbank.bank.in/en/Credit-Cards): current catalogue.
- [RuPay insurance program FY2025–26](https://www.indianbank.bank.in/wp-content/uploads/2025/08/NPCI-Rupay-insurance-programme-FY-2025-26.pdf): validity period through 31 March 2026 only.

## Corrections

- Current MITC: nil joining fee, ₹250 AMC from year two; waiver when prior-year usage exceeds ₹50,000; 3% foreign currency markup; 1.66% monthly purchase finance charge; ₹50 cash-advance fee and 2.25% monthly cash-advance interest.
- Issuer feature sheet: 1 Reward Point worth ₹1 per ₹100 (not ₹200); it does not publish exact exclusions or redemption mechanics.
- Removed claimed 1% fuel surcharge waiver and ₹150 monthly cap: current MITC lists petrol surcharge charges, not a RuPay Platinum waiver.
- Older feature sheet says lounge access is available but provides no current quota. A separate Indian Bank notice ending lounge access from 1 April 2026 applies to RuPay Platinum debit cards, so it was not used to infer credit-card access. Current credit-card entitlement remains unresolved.
- Removed ₹2 lakh personal accident insurance because no current credit-card-specific source supported it. The RuPay insurance program source located expires 31 March 2026; current cover is unconfirmed.
- Launch date and exact reward exclusions/redemption rules remain unknown.
