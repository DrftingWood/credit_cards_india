# Axis RuPay generic landing-page evidence extract (2026-10-26)

Source: [Axis Bank RuPay Credit Card page](https://www.axis.bank.in/cards/credit-card/rupay-credit-card), retrieved 2026-10-26.

This URL is a generic variant chooser/landing page, not a single card SKU. It directs applicants to select an underlying card. Joining and annual fees depend on the selected variant; the issuer separately calls out super.money-specific fees.

## Generic terms the page publishes

- Cash advance fee: 2.5% or INR 500 minimum.
- Foreign-currency transaction fee: 3.5%; monthly finance charge: 3.75%.
- The current generic page lists DCC at 1.5%, but the bankwide terms revision effective 2026-08-28 changes DCC markup to 3.5%. The later effective update is modeled, with the page discrepancy documented.
- The generic page does not state a common reward rate, point value, lounge quota, fuel waiver, or eligibility age/income threshold. These depend on the underlying product.
- RuPay credit cards can be linked to supported UPI applications for merchant payments, subject to issuer/network/app rules. The generic page does not make this a reward-earning guarantee.

## Corrections to the generic record

- Removed a fabricated exact launch date; Axis's 2022 release concerns enabling RuPay credit cards on UPI, not launch of this generic landing-page product.
- Cleared the unsupported RuPay Platinum tier. Network is RuPay by definition; a network tier is not universal across the variant list.
- Removed a generic EDGE Points earn/value claim, an unsupported MCC 6513 exclusion, and values that implied every underlying card shared the same reward program.
- Set variant-specific fees and eligibility to unknown where the landing page does not give a single value. Retained the generic cash-advance, finance and forex figures it publishes.
