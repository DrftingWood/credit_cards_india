# Central Bank of India source verification (27 Oct 2026)

## RuPay Platinum Credit Card

Compared the current CBI credit-card page, FY2019–20 annual report and current application forms directory. CBI reported that standalone issuance was discontinued with co-branded issuance starting October 2019. The current “Central Platinum” PDF is a Visa Platinum application, not evidence for this RuPay product. Card-specific current terms for legacy RuPay Platinum are not published; unsupported prior fee, rewards, benefit and eligibility claims were cleared and status changed to on-hold. See `rupay-platinum-issuer-extract-2026-10-27.md`.

## RuPay Select Credit Card

Compared the current credit-card page, FY2019-20 annual report, current application forms directory and Central Platinum form. No current card-specific terms for the legacy standalone RuPay Select credit card are published; issuer-page RuPay Select material reviewed refers to debit-card products. Unsupported prior terms were cleared and status changed to on-hold. See `rupay-select-issuer-extract-2026-10-27.md`.
